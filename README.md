# 과학 용어 게임 (빙고 · 단어 맞추기)

첫 화면에서 **빙고**와 **단어 맞추기** 중 하나를 골라 하는 수업용 웹 게임입니다.

| 주소 | 내용 |
| --- | --- |
| `https://ssh9873210-commits.github.io/bingo/` | 첫 화면 (게임 선택) |
| `https://ssh9873210-commits.github.io/bingo/bingo.html` | 빙고 (진행자: 끝에 `#host`) |
| `https://ssh9873210-commits.github.io/bingo/word.html` | 단어 맞추기 (관리자: 끝에 `#host`) |

## 단어 맞추기

- 첫 화면에서 **비밀번호 2026**을 입력해야 열려요. (`index.html`과 `word.html`의 `PASSWORD`에서 바꿀 수 있어요.)
- 제한 시간(60초) 내내 용어 풍선이 끝없이 쏟아져요. **찾아야 할 용어**(31개)만 골라 최대한 많이 터뜨려요. 같은 용어도 계속 다시 나와요. 정답 +10, 틀린 용어 −5.
- 게임은 학생 기기 안에서만 진행되고, **랭킹을 불러올 때와 등록할 때만** Supabase를 써요.
- 끝나면 닉네임(최대 10글자)으로 랭킹에 등록해요. 같은 닉네임은 **더 높은 점수 하나만** 남아요(대소문자 구분 없음). 랭킹은 TOP 15까지 보여요.
- 관리자: `word.html#host`에서 진행자 계정으로 로그인하면 기록별 **삭제**와 **랭킹 전체 삭제**를 할 수 있어요.
- 정답 용어(`TARGETS`)와 틀린 용어(`DECOYS`), 제한 시간과 점수는 `word.html` 맨 위 **게임 설정**에서 바꿀 수 있어요.
- 처음 한 번 Supabase SQL Editor에서 `supabase-word.sql`을 실행해야 랭킹이 동작해요.

## 빙고

진행자가 정한 용어로 학생마다 다르게 섞인 5×5 빙고판을 만드는 수업용 웹 빙고입니다.

- 학생은 **로그인 없이** 링크만 열면 됩니다.
- 진행자가 게임 도중 **용어 칸을 없애거나**, **두 칸의 위치를 교환**하면 모든 학생 화면에 바로 반영됩니다.
- 학생의 판 배치와 표시는 각자 브라우저에만 저장됩니다. 서버(Supabase)에는 진행자 설정만 올라갑니다.

## 설정 방법 (처음 한 번, 약 10~20분)

### 1. Supabase 프로젝트 만들기
1. <https://supabase.com> 에 가입하고 **New project**를 만듭니다. (무료 요금제로 충분해요.)
2. 프로젝트가 준비될 때까지 1~2분 기다립니다.

### 2. 테이블 만들기
1. `supabase.sql` 맨 아래의 `teacher@example.com`을 **선생님 이메일**로 바꿉니다.
2. 대시보드 왼쪽 **SQL Editor** → **New query**에 `supabase.sql` 내용을 통째로 붙여 넣고 **Run**을 누릅니다.

### 3. 진행자 계정 만들기
1. **Authentication → Users → Add user → Create new user**
2. 2단계에서 적은 이메일과 비밀번호를 넣고 **Auto Confirm User**를 체크한 뒤 만듭니다.
3. (권장) **Authentication → Sign In / Providers**에서 **Allow new users to sign up**을 끕니다. 다른 사람이 계정을 만들 수 없게 됩니다. (꺼 두지 않아도 `game_hosts`에 없는 계정은 게임을 바꿀 수 없어요.)

### 4. config.js 채우기
1. **Project Settings → Data API**에서 **Project URL**을 복사합니다.
2. **Project Settings → API Keys**에서 **Publishable key**(`sb_publishable_...`)를 복사합니다. 화면에 **Legacy API Keys** 탭이 있다면 그 안의 **anon public** 키를 써도 됩니다.
3. `config.js`의 `YOUR-PROJECT...`와 `YOUR-ANON-KEY`를 바꾸고 커밋합니다.
   - Publishable(anon) 키는 공개돼도 되는 키입니다. **Secret key(`sb_secret_...`)나 service_role 키는 절대 넣지 마세요.**

### 5. GitHub Pages로 게시
1. 저장소 **Settings → Pages**
2. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** → **Save**
3. 1~2분 뒤 아래 주소로 접속할 수 있습니다.

## 사용 방법

- **학생용 링크**: `https://ssh9873210-commits.github.io/bingo/` (첫 화면에서 빙고 선택) 또는 `.../bingo/bingo.html`
- **진행자용 링크**: `https://ssh9873210-commits.github.io/bingo/bingo.html#host` → 진행자 이메일로 로그인

게임 흐름:
1. **게임 시작 전**: 학생은 **판 섞기**로 원하는 만큼 판을 섞어요. 아직 칸은 표시할 수 없어요.
2. **게임 시작** (진행자): 섞기가 막히고, 학생마다 마지막으로 섞은 판으로 게임이 시작돼요. 이제 칸을 눌러 표시해요.
3. **게임 초기화** (진행자): 표시, 없앤 칸, 교환이 모두 지워지고 다시 "게임 시작 전"으로 돌아가요.

게임 중 진행자 화면에서 할 수 있는 것:
- **용어 없애기**: 용어를 누르면 그 칸이 모든 학생 판에서 막힙니다. 막힌 칸이 들어간 줄은 빙고가 될 수 없어요. 다시 누르면 되살아납니다.
- **칸 교환**: 위치 두 곳(예: 1행 1열, 1행 5열)을 고르고 **교환**을 누르면 모든 학생 판에서 그 위치가 바뀝니다. 학생마다 판이 달라서 바뀌는 용어는 학생마다 다를 수 있어요. 표시는 용어를 따라 함께 옮겨갑니다.
- **FREE 고정**: 위치 하나를 고르고 **FREE로 고정**을 누르면 모든 학생 판의 그 위치가 FREE가 되고 자동으로 표시돼요. 삭제된 용어 자리여도 FREE가 되면 쓸 수 있어요. FREE 칸은 교환·밀기에 움직이지 않고, **FREE 해제**를 누르면 원래 용어가 다시 나타나요.
- **줄 밀기**: 행의 ◀ ▶ 또는 열의 ▲ ▼를 누르면 모든 학생 판에서 그 줄이 한 칸씩 밀려요. 끝 칸은 반대쪽 끝으로 넘어가고, FREE 칸은 제자리에 있어요. **마지막 변경 되돌리기**로 교환과 밀기를 하나씩 취소할 수 있어요.

언제든 할 수 있는 것:
- **용어 바꾸기**: 용어를 바꾸고 **용어 적용**을 누르면 게임이 초기화되고 모든 학생 판이 새 용어로 섞여요.

## 알아 둘 점

- Supabase 무료 프로젝트는 **일주일 동안 쓰지 않으면 일시 정지**됩니다. 수업 전에 대시보드에서 **Restore**를 눌러 다시 켜 주세요.
- 학생 화면 오른쪽 위에 **실시간 연결됨**이 보이면 정상입니다.
- 수업 전에 창 두 개(진행자, 학생)를 열어 칸 없애기와 교환이 바로 반영되는지 한 번 확인해 보세요.
